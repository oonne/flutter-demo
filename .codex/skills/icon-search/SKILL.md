# 图标搜索

## 概述

搜索或绘制符合项目设计风格的 SVG 图标，保存到 `assets/icon/` 目录，保证新图标与现有图标风格一致、命名规范、可直接用于 Flutter 渲染。

## 项目路径

本项目为 Flutter 应用（`pubspec.yaml` 中包名为 `flutter_demo`），图标统一存放在仓库根目录的 `assets/icon/`。所有图标均以此目录为基准，保存路径、命名均参照该目录中的现有文件。

## 项目图标风格规范

### 阿里巴巴国际站图标库风格

| 规范项 | 要求 |
| --- | --- |
| 尺寸 | 1024 × 1024 viewBox |
| 风格 | 扁平化、简洁线条 |
| 路径 | 单路径绘制，无渐变、阴影 |
| 颜色 | 单色，由代码动态渲染 |
| 变体 | 描边（line）与填充（fill）两种版本 |
| 圆角 | 统一的圆角处理 |
| 命名 | 小写字母 + 中划线，fill 变体加 `-fill` 后缀 |

### 现有图标示例

`assets/icon/` 中已有 `home.svg`、`home-fill.svg`、`search.svg`、`add.svg` 等图标。动手前先查看现有图标，保持风格与命名一致。

## 工作流程

### 步骤 1：解析需求

明确用户需要的图标语义与变体（描边 / 填充）。

### 步骤 2：按优先级搜索图标

1. 访问 https://www.iconfont.cn/collections/detail?cid=19238 ，在阿里巴巴国际站图标库中搜索并下载 SVG。
2. 未找到时，在 https://www.iconfont.cn/ 搜索风格相近的图标。
3. 仍无合适图标时，按下方风格规范手动绘制 SVG。

### 步骤 3：处理图标

- 确保 viewBox 为 1024 × 1024。
- 移除多余属性与元数据，保留纯路径，保持单色。
- 检查是否符合扁平、简洁线条风格。

### 步骤 4：保存图标

- 保存到 `assets/icon/`。
- 使用小写字母 + 中划线命名（如 `shopping-cart.svg`）。
- 填充版本添加 `-fill` 后缀（如 `shopping-cart-fill.svg`）。

## 示例

用户输入“帮我找一个购物车图标”：

1. 在阿里巴巴国际站图标库搜索“购物车”。
2. 找到合适图标并下载 SVG。
3. 按规范检查并清理 SVG。
4. 保存为 `assets/icon/shopping-cart.svg`，回复保存路径。

## 注意事项

- 保持新图标与现有图标风格一致。
- 命名只使用小写字母和中划线，避免特殊字符。
- 确保 SVG 有效且可在 Flutter 中渲染。
- 保持文件简洁，移除不必要的元数据。
